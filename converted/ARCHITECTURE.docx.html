    UI->>Cop: POST /copilot/query {question}
    Cop->>GW: Forward request (auth token)
    GW->>Auth: Validate token
    Auth-->>GW: OK
    GW->>Orchestrator: invoke_copilot(question, context)
    Orchestrator->>Classifier: classify_intent(question)
    Classifier-->>Orchestrator: intent=unapplied_cash, confidence=0.94
    Orchestrator->>Ledger: fetch_unapplied_cash()
    Ledger-->>Orchestrator: amount= $1.2M, source=Lockbox #1234
    Orchestrator->>Audit: log_copilot_interaction(user,question,answer,confidence)
    Audit-->>Orchestrator: OK
    Orchestrator-->>Cop: answer + evidence + confidence
    Cop-->>UI: Render chat bubble (evidence links)
    UI-->>User: Display answer with “Approve Action” button

Key security & audit points are highlighted in the sequence: token validation, role‑based access, audit‑log write before any UI display.

5. Technical Architecture

Concern Decision Rationale (Tool Selection)
Runtime Kubernetes (EKS / AKS) Cloud‑native orchestration, auto‑scaling, pod‑security‑policies, multi‑AZ resilience
Language Stack Java 17 (Spring Boot) + TypeScript (React) Enterprise‑grade, strong typing, mature security libraries, aligns with existing Meridian stack
AI Orchestration LangChain (Python) running as side‑car containers Proven LLM workflow, easy integration with Azure OpenAI, supports tool‑use & memory
Message Bus Apache Kafka (Confluent Cloud) High‑throughput, exactly‑once semantics for finance events

Search / Analytics ElasticSearch + Kibana Full‑text search on statements, exception clustering, audit‑log exploration
Observability OpenTelemetry SDK (Java & Python) → Prometheus + Grafana + ELK End‑to‑end tracing across micro‑services, supports compliance reporting
CI/CD GitHub Actions + ArgoCD Declarative GitOps, automated security scans (Trivy, Semgrep, SonarQube)
Secrets Management HashiCorp Vault (auto‑unseal via Cloud KMS) Centralised secret rotation, least‑privilege token issuance
Static Code Analysis Semgrep + SonarQube Community Detect OWASP Top‑10, enforce coding standards
Container Scanning Trivy CVE detection, SBOM generation for supply‑chain security
Synthetic Data Generator Faker + custom Python scripts (containerized) Guarantees no PII, reproducible test data sets

All tools are event‑approved (listed in the Enterprise‑Approved Tool List) and have been vetted for no real customer data ingestion.

7. Security Architecture

7.1 Security Principles

  1. Zero Trust – Verify every request, never trust network location.
  2. Least Privilege – Role‑based access (RBAC) enforced by Keycloak + OPA policies.
  3. Defense in Depth – Network segmentation, pod‑security‑policies, WAF, runtime security.
  4. Secure AI – Prompt‑registry, model‑card, confidence thresholds, human‑in‑the‑loop for any monetary action.
  5. Data Protection – Encryption‑in‑transit (TLS 1.3), encryption‑at‑rest (AES‑256), tokenization for account numbers.
