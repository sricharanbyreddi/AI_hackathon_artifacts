Spendid Project – Enterprise Starter‑Code Architecture

Industry: Insurance – Brokerage Finance Operations
Application Type: Enterprise‑grade Finance‑Control Command Center
Core Stack:

Layer Technology Reason for Selection
Frontend Streamlit (Python) + React (optional for heavy UI) Rapid UI prototyping, native Python integration with AI agents, easy to embed in internal portals.
Backend API FastAPI (Python) High‑performance async, OpenAPI auto‑generation, strong typing, built‑in security utilities.
AI Orchestration LangChain + Azure OpenAI Service (or OpenAI GPT‑4o) Agentic workflow, prompt chaining, model‑level cost‑tracking, enterprise‑grade compliance (data residency, VNet).
Database PostgreSQL 15 (RDS/Azure‑Postgres) ACID, row‑level security, native JSONB for audit logs, mature ecosystem, easy horizontal scaling via read‑replicas.
Auth / Identity OAuth 2.0 / OpenID Connect via Keycloak (self‑hosted) Centralised identity, fine‑grained role‑based access (RBAC), MFA, audit trails, SAML/AD integration.
Containerisation Docker + Docker‑Compose (local) / Kubernetes (EKS/AKS) Immutable infrastructure, reproducible builds, auto‑scaling, zero‑downtime deployments.
IaC Terraform (AWS/Azure) Declarative, version‑controlled infra, compliance guardrails (policy as code).
CI/CD GitHub Actions Integrated with repo, secret‑scanning, SAST/DAST, automated test & deployment pipelines.
Observability OpenTelemetry, Prometheus, Grafana, ELK End‑to‑end tracing, metrics, log aggregation, audit‑ready dashboards.
Static & Dynamic Security Semgrep, SonarQube CE, OWASP ZAP Code‑quality, SAST, DAST, policy enforcement.
Prompt & Model Registry SQLite (internal) + JSONL export Lightweight, auditable record of every LLM interaction.

Governance Note – All tools are event‑approved (open‑source or enterprise‑grade SaaS) and do not ingest any real customer data. Synthetic data generators are provided in the repo.

3. Security, Compliance & Governance

Area Controls Implementation
Authentication & Authorization OAuth2/OIDC, RBAC, MFA, token revocation Keycloak as IdP; FastAPI dependency get_current_user validates JWT; role‑based scopes (finance:read, finance:write, ai:execute).
Data Protection Encryption‑at‑rest, encryption‑in‑transit, column‑level masking RDS Transparent Data Encryption (AES‑256); TLS 1.3 for all HTTP; PostgreSQL pgcrypto for PII fields; row‑level security policies for audit logs.
Auditability Immutable audit trail, tamper‑evidence audit_log table with jsonb payload, created_at, user_id; write‑only via stored procedure; logs shipped to ELK with hash‑chain verification.
Compliance SOC‑2, ISO‑27001, GDPR (data‑subject rights) Terraform guardrails enforce VPC isolation, IAM least‑privilege; Data‑subject deletion endpoint (/privacy/erase).
Secure Coding SAST, DAST, secret scanning, dependency checks GitHub Actions run Semgrep, Bandit, OWASP ZAP, Trivy; git‑secret prevents committing credentials.
Least‑Privilege AI Model‑level access control, prompt‑level guardrails LangChain wrapper checks user scope before invoking LLM; system prompt includes “Never disclose raw PII”.
Observability & Incident Response Centralised logging, metrics, alerting OpenTelemetry instrumentation in FastAPI & Streamlit; Prometheus alerts on latency > 500 ms, error‑rate > 1 %.
Disaster Recovery Automated backups, point‑in‑time restore RDS automated snapshots (daily, 35‑day retention); Kubernetes Velero backups for stateful sets.
Governance Code review, change‑control, versioning Mandatory PR approvals (2 reviewers), CODEOWNERS for security‑critical modules, semantic versioning.

Sample FastAPI Security Dependency

# core/security.py
from fastapi import Depends, HTTPException, status
from fastapi.security import OAuth2AuthorizationCodeBearer
from jose import jwt, JWTError
from pydantic import BaseModel
from typing import List

oauth2_scheme = OAuth2AuthorizationCodeBearer(
    authorizationUrl="https://keycloak.example.com/auth/realms/spendid/protocol/openid-connect/auth",
    tokenUrl="https://keycloak.example.com/auth/realms/spendid/protocol/openid-connect/token",
)

class TokenPayload(BaseModel):
    sub: str
    scopes: List[str] = []

def get_current_user(token: str = Depends(oauth2_scheme)):
    try:
        payload = jwt.decode(token, "PUBLIC_KEY_PLACEHOLDER", algorithms=["RS256"])
        token_data = TokenPayload(**payload)
    except (JWTError, ValidationError):
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Could not validate credentials",
        )
    return token_data

def require_scope(required: str):
    def wrapper(user: TokenPayload = Depends(get_current_user)):
        if required not in user.scopes:
            raise HTTPException(status_code=403, detail="Insufficient scope")
        return user
    return wrapper
