RECOVERY PACKAGE

This package restores the project code and styling from v17, before the v18 regression.

The original project uploads remain in uploads/. The three latest user-provided Word documents are additionally preserved in uploads/recovery_originals/.

Extract this ZIP into a NEW folder. Do not overwrite your current project. Install requirements with: pip install -r requirements.txt
Run with: python app.py

This is a rollback to the previous version, not a claim that every formatting issue in v17 is fixed. Test it before replacing any working copy.
